# 安全说明

**中文(默认)** · [English](security.en.md)

goder 的安全模型速览(桌面 App、嵌入库、多用户网关三种形态共用)。
涉及区域的代码不变量另见 [AGENTS.md](../AGENTS.md)。

## 令牌边界(核心原则)

- gh server 的用户级令牌**不下发浏览器**:托管模式(桌面与网关)由
  服务端反代注入 `Authorization` 头,并覆盖浏览器侧可能携带的凭证;
  浏览器一律经同源 `/goder-api` 访问(gh server 无 CORS 头,直连既跨域
  失败也不安全)。
- 唯一例外是「直连外部 gh server」的单用户模式(`GODER_UPSTREAM`),
  由使用者自己持有令牌,网关不做注入。

## 身份与信任模型

三种身份模式(`GODER_IDENTITY`),信任边界各不相同:

| 模式 | 信任基础 | 部署约束 |
|---|---|---|
| `single` | 无身份,所有人共用一个进程 | 本机/内网联调 |
| `header` | 完全信任上级网关注入的用户头 | **只能部署在已完成鉴权的可信反代之后**;直接暴露等于放开全部用户数据 |
| `sso` | Casdoor OAuth2 授权码 + 本地会话 | 独立部署的完整方案 |

sso 细节:state 一次性校验(校验即清)、会话令牌 32 字节加密随机数、
HttpOnly + SameSite=Lax cookie;TLS 卸载部署显式设 `COOKIE_SECURE=1`;
`AUTH_DEV_EMAIL` 是本地联调后门(免 SSO 直接签发会话),**生产必须留空**;
本地会话表可经 `GODER_SESSIONS_FILE` 落盘(0600 原子写,单实例定位)。

## 进程与数据隔离(多用户网关)

- 一个登录用户一个独立 `gh server` 子进程:独立端口(池 17400-18400)、
  独立数据目录、独立 `GRF_HOME`(settings/技能/插件全部按用户隔离)。
- uid 经白名单清洗映射为目录名(防路径穿越;`..` 等点段一并折叠),
  用户间目录互不可达。
- 进程数量上限、空闲回收、崩溃重启冷却,防资源耗尽。
- 反代对无长度请求体设缓冲上限(默认 64MB),堵内存 DoS。

## 管理面(/admin/*)

- Bearer `GODER_ADMIN_TOKEN` 鉴权,常量时间比较;不配置即关闭。
- **权限等同服务器代码执行**:插件安装端点落的 wrapper 会被 gh 以服务
  用户身份执行。只在内网/可信网络传递,用长随机值,不进 URL 与前端代码。
- 进程生命周期事件可经 webhook 回调,`GODER_WEBHOOK_SECRET` 配置后
  附 HMAC-SHA256 签名头(跨信任域回调必配)。

## CORS

默认 `*` 通配是**本地联调**用的;公网部署必须用 `GODER_CORS_ORIGINS`
白名单精确放行(回显命中的 Origin 并允许凭据,兼容 cookie 会话)。

## 桌面 App 本地防线

- 本地 HTTP 服务只监听 127.0.0.1;敏感路径(`/goder-api*`、`/wails/*`)
  带本机 Host 白名单(127.0.0.1 / localhost / *.localhost),防 DNS
  rebinding 把回环服务暴露给外域页面——wails 的调用通道自身不做来源
  校验,这层守卫是必须的。
- `/goder-api/token`(连接信息)与 `/goder-api/local-file`(本地文件
  只读)双端点额外收敛:local-file 限白名单目录(用户主目录/gh 数据
  目录/项目索引登记目录,符号链接求值后比对)+ 64MB 上限 + nosniff。
- goder-console MCP(智能体控制面板浏览器/终端/界面)仅绑 127.0.0.1 +
  随机令牌(常量时间比较);wrapper 0700,令牌经环境变量传递、不进
  进程参数(ps 不可见)。

## 下载完整性(供应链)

gh 引导下载、goder 自更新、插件/技能在线安装,落盘前一律按**同目录
校验面**验证 sha256:`<file>.sha256` 优先、`SHA256SUMS` 清单回落。
校验面存在即强制匹配(不匹配不落盘不执行),皆无(历史已发目录)跳过
并记日志;发布侧 CI 为每个产物随发 `.sha256`。全部下载走 HTTPS。

## 前端 XSS 防线

- markdown 渲染自研:全部输入先 HTML 转义再做受限转换,链接/图片仅
  放行 `http(s)://`(拒 `javascript:` 等协议),无 `eval`/`new Function`。
- 嵌入库 shadow DOM 样式自隔离;换肤只经 `--goder-*` CSS 变量。

## 错误与日志

面向浏览器的错误应答只给归类后的通用文案(容量/未就绪/上游不可用),
内部细节(地址、路径、启动日志位置)只进服务端日志。
