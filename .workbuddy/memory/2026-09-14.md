## 消除 macOS 链接警告(ld: object file ... built for newer 'macOS' 26.0 than being linked 11.0)

- 根因:Go 链接器 darwin/arm64 固定按 minos 11.0 生成 LC_BUILD_VERSION,而本机
  CommandLineTools SDK 27.0(macOS 26.6)下 clang 默认把 C/ObjC 目标文件编成 26.0,
  两者不一致 → 每条 cgo 目标文件一条 ld 警告。
- 修复:在 `build.sh` 的 Go 构建步骤前(Darwin 守卫内)固定部署目标:
  `MACOSX_DEPLOYMENT_TARGET=11.0` + `CGO_CFLAGS/CGO_LDFLAGS` 追加
  `-mmacosx-version-min=11.0`(CGO_CFLAGS 会覆盖默认值,故需带上 `-O2 -g`);
  可用 `MACOS_MIN_VERSION` 环境变量覆写。
- 验证:加变量后构建零警告,产物 `otool -l` → minos 11.0 / sdk 27.0;
  去掉变量对照组复现 9 条警告。注意:wails v3 的 cgo 对象编译通过,11.0 无 API 兼容问题。
